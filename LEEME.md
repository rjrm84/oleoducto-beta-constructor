# Oleoducto Beta · Constructor de ductos

- `index.html` — constructor de ductos a medida (trazado sobre mapa, altimetría real, caño, estaciones,
  bombas, válvulas, medición, destino y revisión con el motor hidráulico).
- `simulador.html?ducto=ID` — simula un ducto guardado (vista 3D, sala de control, SCADA, desafío).

Las mejoras se prueban primero en Oleoducto Beta (https://github.com/rjrm84/oleoducto-beta) y después se pasan acá.
En línea: https://rjrm84.github.io/oleoducto-beta-constructor/
